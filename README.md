# AI Commerce OS — DE / TR

100% kostenlose, zweisprachige digitale Produktbibliothek für Deutschland.

## Enthalten
- 100 digitale Produkte
- 10 Kategorien
- Deutsch 🇩🇪 + Türkçe 🇹🇷
- Alle Produkte kostenlos
- Direkte Downloads ohne Checkout
- Produkt-Suche und Kategorienfilter
- Produkt-Detailansicht
- DE/TR Umschaltung
- WhatsApp, Telegram, E-Mail, native Share und Link-Kopieren
- Lokale persönliche Bibliothek im Browser
- Responsive Premium-Storefront

## Betrieb
Die Website ist vollständig statisch und kann kostenlos über GitHub Pages veröffentlicht werden. Es gibt aktuell keinen Zahlungsanbieter, keinen Checkout und keine benötigten Secrets.
